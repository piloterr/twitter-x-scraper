# X (Twitter) Scraper API – code examples

Examples for every X (Twitter) endpoint of the [Piloterr API](https://www.piloterr.com). Python and TypeScript examples are in the [main README](../README.md).

```bash
export PILOTERR_API_KEY="your-api-key"   # get one at https://app.piloterr.com
```

| Language | File | Run |
|---|---|---|
| cURL (Bash) | [`curl/post_info.sh`](curl/post_info.sh) | `bash post_info.sh` |
| cURL (Bash) | [`curl/profile_info.sh`](curl/profile_info.sh) | `bash profile_info.sh` |
